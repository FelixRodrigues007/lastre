Motor de prova e viabilidade do lote. A S/A assina o cliente, faz logística e venda. Lastre não compra, não transporta, não refina, não emite token e não aparece no contrato comercial do metal.

Divisão de papéis (não negociável)

Lastre — proof engine

Faz

  • Recebe o pacote de evidência (hashes, não PDFs públicos)
  • Confere consistência: origem ↔ ensaio ↔ barra ↔ custódia
  • Emite veredito Valid / Invalid
  • Sela o lote (SHA-256) e ancora a prova
  • Abre ou fecha o gate de tokenização
  • Libera leitura seletiva (PCQ) só a quem a S/A autorizar
S/A — commercial + ops

Faz

  • Contrato inteligente / SPA com o cliente
  • Compra, transporte, refino, exportação, vault, venda
  • Relação com refinaria, seguradora, issuer EUA
  • KYC/AML comercial e câmbio
  • Logística e prazo com o metal

Lastre não assina, não opera, não lastreia preço.

O que “ouro bom” significa (e o que não significa)

Lastre não garante cotação, liquidez nem seguro do metal. Lastre garante que o lote só passa se o pacote de prova fechar — origem, teor, cadeia de custódia e custódia batem. Isso é a viabilidade para token: o ouro é tratável como bom para o gate.

Privacidade (pedido do cliente)

On-chain opaco

Só hash + veredito + lot ID cego (ex. AU-26W34-07). Zero nome, cidade, CNPJ, kg em claro.

Docs off-chain

NF-e, PLG, laudo e SKR ficam no cofre da S/A. Lastre vê o necessário sob NDA e sela o hash.

Buyer/auditor só lê via PCQ autorizado pela S/A. Sem marketplace público. Sem post. Sem grupo Casper.

Pacote mínimo para Valid (senão o gate não abre)

  • Identificação do lote (ID interno da S/A) + peso + teor declarado
  • Título minerário vigente do vendedor (PLG/ANM) coerente com a NF-e
  • NF-e de primeira aquisição + comprovante CFEM quando aplicável
  • Guia de transporte + evidência de custódia em trânsito
  • Laudo de teor independente (999) da refinaria/lab nomeado
  • SKR / termo de vault antes do mint (não depois)

Falta um item = Invalid = a S/A não emite token. Isso é o produto. Invalid também é prova — e permanece privado.

Demonstração de papel. Lastre não é seguro de ouro, não é oferta de token e não afirma origem sem o pacote mínimo. Prova ≠ preço. Valid ≠ promessa de venda. Invalid bloqueia o mint — isso é a garantia operacional que o cliente pediu.
