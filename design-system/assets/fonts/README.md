# Manrope

Source: https://github.com/google/fonts/tree/main/ofl/manrope
License: SIL Open Font License 1.1 (see `Manrope-OFL.txt`).

The official variable font was converted to WOFF2 with fontTools, preserving its 200–800 weight axis. Glyph outlines were not redrawn.

Manrope is used for app and website headings. Inter and JetBrains Mono retain the existing Google Fonts loading in `app/index.html` and `web/index.html`. The logo is a separate original SVG, independent of typography tokens.
